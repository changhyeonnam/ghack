LedgerLens is an underwriting copilot for thin-file small businesses in Southeast Asia. It reads the evidence they actually have (bank statement PDFs, Shopee dashboard screenshots, receipts, handwritten ledgers, shop photos) and drafts a credit memo in which every number links to a document, page and bounding box. A separate Challenger agent then attacks the memo with deterministic checks, and a human underwriter accepts or dismisses each objection and signs.
Gemini 3.8 Flash, orchestrated with the Agent Development Kit, runs intake, multimodal extraction, the memo, the Challenger and the customer letter. Cloud Run serves the FastAPI backend and the React app. Firestore stores cases, extractions, memos, objections, decisions, the audit trail and the LLM cache; Cloud Storage holds the documents; Firebase Hosting serves the frontend.
On a live run over 3 synthetic businesses with 20 planted traps, LedgerLens caught 18 vs 3 for a single prompt, with 0 vs 62 unsourced numbers.
